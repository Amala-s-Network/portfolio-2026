# Solte as imagens aqui

Esta é a pasta de entrada. Joga tudo aqui do jeito que estiver: PNG, JPG, GIF, MP4, print
do Figma, export do Miro. Não precisa renomear, converter nem redimensionar.

O que eu faço depois que você me avisa:

1. converto para WebP e corto no enquadramento certo;
2. movo para `public/cases/<slug>/`, que é de onde o site serve;
3. ligo em `content/copy.ts`, na prancha da seção certa;
4. apago o arquivo pesado daqui, para o repositório não engordar.

## Ajuda muito se o nome disser de qual case é

Não é obrigatório, mas encurta o caminho:

```
ink-aparencia-antes.png
ink-aparencia-depois.png
itau-contestacao-tracking.png
ems-simulador-persona.png
```

Se não der, manda assim mesmo e me diz na conversa o que é cada uma.

## Vale mandar mesmo que esteja "meio feio"

Board do Miro bagunçado, wireframe de baixa, print de reunião: isso mostra como você pensa e
recrutador reconhece trabalho real. Uma tela final bonita sozinha diz menos.

## Só uma coisa antes de mandar

Dado de cliente legível na tela. Se tiver, desfoca antes — as telas do Itaú e da EMS são
interface real, e hoje elas saem marcadas como pendentes de avaliação de NDA no site.
